## Engineering focus

- Python desktop applications (Tkinter) packaged as standalone Windows executables with installers and shortcuts
- Data integrity: source, unit and status on every value; missing data reported, never invented
- Automated verification with pytest, headless GUI runs and reproducible test reports
- Caching and validation for delayed market data; explicit failure states instead of silent fallbacks
- Backend services for scheduled reports (FastAPI, PostgreSQL), tested against a real database
- Technical documentation, known-limitations registers, and build/install tooling

## How I work

Evidence before claims. I label data as live, cached, delayed or stale; keep GBP and GBX separate; write down limitations instead of hiding them; and prefer a clear `WATCH` over a forced verdict. No win-rate, return or "accuracy" claims.
